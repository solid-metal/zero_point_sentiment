# zero_point_sentiment
A Machine Learning (ML) system designed to perform fine-grained sentiment analysis on user feedback. By utilizing Natural Language Processing (NLP), the model transforms raw text into a numerical satisfaction score on a scale of 1 to 10.

Project Title: Zero-Point Sentiment
Project Overview
This project aims to develop a Machine Learning (ML) based system capable of performing fine
grained sentiment analysis on user feedback and reviews. The system uses Natural Language 
Processing (NLP) techniques to analyze textual input and predict a satisfaction score on a scale of 1 
to 10 instead of only classifying text as positive, negative, or neutral.
The main objective is to create a smart feedback evaluation model that understands user emotions 
and opinions more accurately. This can help businesses, educational platforms, and online services 
better understand customer satisfaction levels.
Problem Statement
Traditional sentiment analysis systems usually classify reviews into broad categories such as 
positive or negative. However, these categories often fail to capture the exact intensity of user 
satisfaction. Our project focuses on predicting a detailed numerical rating based on textual 
feedback.
Objectives
• To preprocess and clean textual feedback data. 
• To convert text into machine-readable numerical features using NLP techniques. 
• To train a Machine Learning model for sentiment score prediction. 
• To generate satisfaction scores ranging from 1 to 10. 
• To improve the accuracy of customer feedback analysis.
Technologies and Methods
• Technologies
▪ Python 
▪ Scikit-learn 
▪ Pandas & NumPy 
▪ Natural Language Toolkit (NLTK) 
• Machine Learning Techniques
▪ TF-IDF Vectorization 
▪ Sentiment Analysis 
▪ Regression Models / Classification Models 
▪ NLP Text Preprocessing
Expected Outcome
The proposed system will automatically analyze user feedback and provide a detailed satisfaction 
score from 1 to 10. This project can help organizations understand customer opinions more 
effectively and make better decisions based on user experience
